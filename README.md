# Uppfire

Static premium agency site adapted to the user's Melius reference. `dist/` is the complete site. The shared Scrollcraft engine is unchanged; bespoke interactions (portfolio ring, work viewer, films and reels, brief) live in `dist/app.js`; the real-work layer is styled in `dist/work.css`.

The site has semantic content, locally hosted reference fonts/media, responsive compositions, reduced-motion support, service tabs, native FAQ disclosures, and a project brief download. The portfolio, films and results are real client work supplied by the studio (see `scrollcraft/builds/uppfire/ASSETS.md`). Contact runs through WhatsApp (+92 330 5078441): the project brief opens a pre-filled WhatsApp message or downloads as a file. There is no server-side lead capture.

Design notes, reference asset provenance and verification limits are in `scrollcraft/builds/uppfire/`.

`review/uppfire-preview.html` is a self-contained snapshot of revision 5 and predates the real-work portfolio.
